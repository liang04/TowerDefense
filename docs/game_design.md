# 花园防线设计说明

## 游戏定位

这是一个小型 2D 格子塔防游戏。玩法保留传统路径塔防：僵尸沿固定道路推进，玩家在道路旁种植植物防守。目标是让新手能看懂、能调数值、能逐步扩展。

## 核心循环

1. 玩家获得初始阳光和生命。
2. 玩家在非道路格子上种植植物。
3. 按右键或空格开始波次。
4. 僵尸沿固定道路移动，到达终点扣生命。
5. 植物自动攻击僵尸，击退僵尸获得阳光。
6. 波次结束后，玩家用阳光补种、升级或铲除植物。
7. 清完全部波次获胜，生命归零失败。
8. 如果还有下一关，胜利结算界面可以进入下一关。

## 当前操作

- 绿色地块：可以种植。
- 土色道路：僵尸行进路线，不能种植。
- 底部植物按钮或 `1`：选择豌豆射手，基础输出，便宜、射速快。
- 底部植物按钮或 `2`：选择爆裂果，射速慢、伤害高、范围溅射。
- 底部植物按钮或 `3`：选择寒冰花，伤害低，但会减速僵尸。
- 鼠标左键空地：种植当前选择的植物。
- 鼠标左键已有植物：选择该植物。
- 底部“升级”按钮或 `U`：升级选中的植物。
- 底部“铲除”按钮或 `X`：铲除选中的植物。
- 顶部“开始”按钮、右键或空格：开始第一波。
- 顶部“暂停/继续”按钮、`P` 或 `Esc`：暂停/继续游戏。
- 顶部“重开”按钮或 `R`：重开当前关卡。
- 顶部“切换关卡”：选择要练习的地图。

## 植物设计

| 植物 | 定位 | 特点 |
| --- | --- | --- |
| 豌豆射手 | 基础输出 | 便宜、射速快、适合前期铺场 |
| 爆裂果 | 高伤害 | 单次伤害高、射速慢、适合打高血量僵尸 |
| 寒冰花 | 控制 | 伤害低、可短时间减速僵尸 |

升级规则：每株植物最高 3 级。升级提升伤害、射程和射速，价格随等级增加。

## 僵尸设计

| 僵尸 | 定位 | 特点 |
| --- | --- | --- |
| runner | 疾跑僵尸 | 血少、速度快，考验补刀 |
| grunt | 普通僵尸 | 标准数值 |
| tank | 铁桶僵尸 | 血多、速度慢，考验持续输出 |

## 第一阶段目标

- 核心玩法可完整跑通。
- 数值集中在 `GameManager` 和 `WaveSpawner`，方便调整。
- UI 提示足够清楚，让不懂代码的人也知道怎么操作。

## 第二阶段目标

- 开始界面说明基础操作。
- 暂停界面提供继续和重开。
- 胜利/失败结算显示波次、击退、漏掉、生命和阳光。
- 每波开始前显示倒计时，让玩家有准备时间。

## 第三阶段目标

- 植物发射可见子弹，命中后才结算伤害。
- 命中僵尸时显示扩散特效。
- 僵尸受击时短暂闪白，方便玩家确认攻击生效。
- 僵尸突破终点时显示红色警示特效和扣血提示。

## 第四阶段目标

- 使用代码生成短音效，覆盖射击、命中、击退、漏掉、波次开始、升级、铲除、胜利和失败。
- 三种植物使用不同外观：豌豆射手、爆裂果、寒冰花。
- 三类僵尸使用不同外观：普通僵尸、疾跑僵尸、铁桶僵尸。
- 地图显示起点和终点标记，路径边线更清楚。

## 第五阶段目标

- 地图增加草地背景和固定装饰，不再是纯色底。
- 所有可种植空格常驻显示绿色地块，玩家不用移动鼠标也能看懂哪里能种植物。
- 种植失败时显示明确原因，例如阳光不足、道路不能种植、地图外不能种植。

## 第六阶段目标

- 关卡数据集中到 `scripts/level_data.gd`。
- 当前支持 3 张地图：
  - 草地练习场：标准花园路线，适合学习基础种植和升级。
  - 峡谷回廊：更长路线，僵尸分批更多，适合练习补种和升级。
  - 熔岩急道：路线较短、压力更高，适合练习寒冰花减速和爆裂果集火。
- 每张地图可以配置路径、初始阳光、初始生命、背景颜色、背景图片、可种植地块颜色、道路颜色和波次。
- 胜利后如果还有下一关，结算界面显示“下一关”按钮。

## 第七阶段目标

- 顶部增加“切换关卡”按钮。
- 关卡选择面板可以预览关卡名称、说明、初始阳光、初始生命和波次数。
- 选择关卡后重载当前场景，方便直接测试不同地图。

## 第八阶段目标

- 开局自动高亮推荐种植格子，帮助新玩家知道第一株植物可以放在哪里。
- 底部提示按流程变化：先建议种豌豆射手，种好第一株植物后提示可以继续补种或开始。
- 点击“开始”后隐藏推荐高亮，不干扰正式战斗。

## 第九阶段目标

- 顶部波次显示当前进度和总波次数，例如 `波次: 1/5`。
- 底部显示下一波或本波僵尸组成，例如普通僵尸、疾跑僵尸、铁桶僵尸的数量。
- 根据僵尸类型给出简单种植建议，帮助玩家在波次间做准备。

## 第十阶段目标

- 增加僵尸图例，让玩家能把普通僵尸、疾跑僵尸、铁桶僵尸和地图上的造型对应起来。
- 当前植物和选中植物显示具体属性：伤害、射程、攻击间隔和减速效果。
- 植物信息不只显示描述，方便玩家根据下一波僵尸选择合适植物。

## 第十一阶段目标

- 增加轻量美术资源，覆盖三种植物和三种僵尸。
- 植物使用图标资源显示，保留射程圈、选中框和攻击目标线。
- 僵尸使用图标资源显示，保留血条、受击闪白和减速状态框。

## 第十二阶段目标

- 优化地图背景，增加草丛、石块和草叶等固定装饰。
- 道路增加边缘、碎石和中心路线提示，让僵尸行进路线更像真实道路。
- 起点和终点使用更明确的入口/基地标记，增强目标感。

## 第十三阶段目标

- 增加第 3 张关卡“熔岩急道”。
- 这张地图路线更短、生命更少，要求玩家更早使用寒冰花和爆裂果。
- 波次更早混入疾跑僵尸和铁桶僵尸，强化波次预告和种植建议的价值。

## 后续开发路线

1. 增加背景音乐和音量开关。
2. 给植物和僵尸增加多帧动画。
3. 增加特殊僵尸，例如护盾僵尸、回血僵尸、分裂僵尸。
4. 增加技能，例如全屏伤害、临时加速、冻结道路。
5. 保存通关进度和最佳成绩。
