# 塔防游戏设计说明

## 游戏定位

这是一个小型 2D 格子塔防游戏，目标是让新手能看懂、能调数值、能逐步扩展。先做清晰的核心循环，再逐步增加关卡、塔、敌人和美术。

## 核心循环

1. 玩家获得初始金币和生命。
2. 玩家在非道路格子上建造防御塔。
3. 按右键或空格开始波次。
4. 敌人沿固定道路移动，到达终点扣生命。
5. 防御塔自动攻击敌人，击杀敌人获得金币。
6. 波次结束后，玩家用金币补塔、升级或出售塔。
7. 清完全部波次获胜，生命归零失败。

## 当前操作

- `1`：选择箭塔，均衡、便宜。
- `2`：选择炮塔，射速慢、伤害高。
- `3`：选择冰塔，伤害低，但会减速敌人。
- 鼠标左键空地：建造当前选择的塔。
- 鼠标左键已有塔：选择该塔。
- `U`：升级选中的塔。
- `X`：出售选中的塔。
- 右键或空格：开始第一波。
- `P` 或 `Esc`：暂停/继续游戏。
- `R`：游戏结束后重开。

## 防御塔设计

| 塔 | 定位 | 特点 |
| --- | --- | --- |
| 箭塔 | 基础输出 | 便宜、射速快、适合前期铺场 |
| 炮塔 | 高伤害 | 单次伤害高、射速慢、适合打高血量敌人 |
| 冰塔 | 控制 | 伤害低、可短时间减速敌人 |

升级规则：每座塔最高 3 级。升级提升伤害、射程和射速，价格随等级增加。

## 敌人设计

| 敌人 | 定位 | 特点 |
| --- | --- | --- |
| runner | 快速怪 | 血少、速度快，考验补刀 |
| grunt | 普通怪 | 标准数值 |
| tank | 重甲怪 | 血多、速度慢，考验持续输出 |

## 第一阶段目标

- 核心玩法可完整跑通。
- 数值集中在 `GameManager` 和 `WaveSpawner`，方便调整。
- UI 提示足够清楚，让不懂代码的人也知道怎么操作。

## 第二阶段目标

- 开始界面说明基础操作。
- 暂停界面提供继续和重开。
- 胜利/失败结算显示波次、击杀、漏怪、生命和金币。
- 每波开始前显示倒计时，让玩家有准备时间。

## 后续开发路线

1. 给塔和敌人换成图片或动画。
2. 加入多张地图和关卡选择。
3. 增加特殊敌人，例如护盾怪、回血怪、分裂怪。
4. 增加技能，例如全屏伤害、临时加速、冻结道路。
5. 增加音效和背景音乐。
