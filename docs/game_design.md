# 塔防游戏设计说明

## 游戏定位

这是一个小型 2D 格子塔防游戏，目标是让新手能看懂、能调数值、能逐步扩展。先做清晰的核心循环，再逐步增加关卡、塔、敌人和美术。

## 核心循环

1. 玩家获得初始金币和生命。
2. 玩家在非道路格子上建造防御塔。
3. 按右键或空格开始波次。
4. 敌人沿固定道路移动，到达终点扣生命。
5. 防御塔自动攻击敌人，击杀敌人获得金币。
6. 波次结束后，玩家用金币补塔、升级或出售塔。
7. 清完全部波次获胜，生命归零失败。
8. 如果还有下一关，胜利结算界面可以进入下一关。

## 当前操作

- 绿色地块：可以建塔。
- 土色道路：敌人行进路线，不能建塔。
- 底部塔按钮或 `1`：选择箭塔，均衡、便宜。
- 底部塔按钮或 `2`：选择炮塔，射速慢、伤害高。
- 底部塔按钮或 `3`：选择冰塔，伤害低，但会减速敌人。
- 鼠标左键空地：建造当前选择的塔。
- 鼠标左键已有塔：选择该塔。
- 底部“升级”按钮或 `U`：升级选中的塔。
- 底部“出售”按钮或 `X`：出售选中的塔。
- 顶部“开始”按钮、右键或空格：开始第一波。
- 顶部“暂停/继续”按钮、`P` 或 `Esc`：暂停/继续游戏。
- 顶部“重开”按钮或 `R`：重开当前关卡。
- 顶部“切换关卡”：选择要练习的地图。

## 防御塔设计

| 塔 | 定位 | 特点 |
| --- | --- | --- |
| 箭塔 | 基础输出 | 便宜、射速快、适合前期铺场 |
| 炮塔 | 高伤害 | 单次伤害高、射速慢、适合打高血量敌人 |
| 冰塔 | 控制 | 伤害低、可短时间减速敌人 |

升级规则：每座塔最高 3 级。升级提升伤害、射程和射速，价格随等级增加。

## 敌人设计

| 敌人 | 定位 | 特点 |
| --- | --- | --- |
| runner | 快速怪 | 血少、速度快，考验补刀 |
| grunt | 普通怪 | 标准数值 |
| tank | 重甲怪 | 血多、速度慢，考验持续输出 |

## 第一阶段目标

- 核心玩法可完整跑通。
- 数值集中在 `GameManager` 和 `WaveSpawner`，方便调整。
- UI 提示足够清楚，让不懂代码的人也知道怎么操作。

## 第二阶段目标

- 开始界面说明基础操作。
- 暂停界面提供继续和重开。
- 胜利/失败结算显示波次、击杀、漏怪、生命和金币。
- 每波开始前显示倒计时，让玩家有准备时间。

## 第三阶段目标

- 防御塔发射可见子弹，命中后才结算伤害。
- 命中敌人时显示扩散特效。
- 敌人受击时短暂闪白，方便玩家确认攻击生效。
- 敌人突破终点时显示红色警示特效和扣血提示。

## 第四阶段目标

- 使用代码生成短音效，覆盖射击、命中、击杀、漏怪、波次开始、升级、出售、胜利和失败。
- 三种塔使用不同形状：箭塔尖顶、炮塔炮管、冰塔菱形核心。
- 三类敌人使用不同形状：普通怪方形、快速怪菱形、重甲怪大块状。
- 地图显示起点和终点标记，路径边线更清楚。

## 第五阶段目标

- 地图增加草地背景和固定装饰，不再是纯色底。
- 所有可建塔空格常驻显示绿色地块，玩家不用移动鼠标也能看懂哪里能放塔。
- 放塔失败时显示明确原因，例如金币不足、道路不能建塔、地图外不能建塔。

## 第六阶段目标

- 关卡数据集中到 `scripts/level_data.gd`。
- 当前支持 2 张地图：
  - 草地练习场：标准路线，适合学习基础建塔和升级。
  - 峡谷回廊：更长路线，敌人分批更多，适合练习补塔和升级。
- 每张地图可以配置路径、初始金币、初始生命、背景颜色、可建造地块颜色、道路颜色和波次。
- 胜利后如果还有下一关，结算界面显示“下一关”按钮。

## 第七阶段目标

- 顶部增加“切换关卡”按钮。
- 关卡选择面板可以预览关卡名称、说明、初始金币、初始生命和波次数。
- 选择关卡后重载当前场景，方便直接测试不同地图。

## 第八阶段目标

- 开局自动高亮推荐建塔格子，帮助新玩家知道第一座塔可以放在哪里。
- 底部提示按流程变化：先建议建箭塔，建好第一座塔后提示可以继续补塔或开始。
- 点击“开始”后隐藏推荐高亮，不干扰正式战斗。

## 第九阶段目标

- 顶部波次显示当前进度和总波次数，例如 `波次: 1/5`。
- 底部显示下一波或本波敌人组成，例如普通怪、快速怪、重甲怪的数量。
- 根据敌人类型给出简单建塔建议，帮助玩家在波次间做准备。

## 第十阶段目标

- 增加敌人图例，让玩家能把普通怪、快速怪、重甲怪和地图上的颜色对应起来。
- 当前塔和选中塔显示具体属性：伤害、射程、攻击间隔和减速效果。
- 塔信息不只显示描述，方便玩家根据下一波敌人选择合适防御塔。

## 第十一阶段目标

- 增加轻量 SVG 美术资源，覆盖三种防御塔和三种敌人。
- 防御塔使用图标资源显示，保留射程圈、选中框和攻击目标线。
- 敌人使用图标资源显示，保留血条、受击闪白和减速状态框。

## 第十二阶段目标

- 优化地图背景，增加草丛、石块和草叶等固定装饰。
- 道路增加边缘、碎石和中心路线提示，让敌人行进路线更像真实道路。
- 起点和终点使用更明确的入口/基地标记，增强目标感。

## 后续开发路线

1. 增加背景音乐和音量开关。
2. 给塔和敌人换成图片或动画。
3. 增加特殊敌人，例如护盾怪、回血怪、分裂怪。
4. 增加技能，例如全屏伤害、临时加速、冻结道路。
5. 保存通关进度和最佳成绩。
