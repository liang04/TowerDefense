# 界面字体（拖入即生效）

游戏没有内置字体时，会用 Godot 默认字体。**默认字体不含中文字形**——在
**没有安装中文系统字体**的机器上，所有中文 UI 会显示成方框（□□□）。
打包一个中文字体即可彻底规避这个问题，并让界面更统一。

## 怎么放

把一个字体文件重命名后放到本目录，任选其一（按此优先级匹配）：

```
assets/fonts/ui.ttf      （或 ui.otf / ui.woff2）
```

放进去后游戏启动即把它设为全局界面字体（原默认字体仍作为回退）；
不放则保持引擎默认，游戏照常运行。字体以运行时动态加载，**无需在编辑器里导入**。

## 推荐的免费可商用中文字体

都覆盖中文 + 拉丁，体积适中：

- **思源黑体 / Noto Sans SC**（SIL OFL，免费可商用）
  <https://fonts.google.com/noto/specimen/Noto+Sans+SC>
- **思源宋体 / Noto Serif SC**（SIL OFL）
- **站酷 / 阿里巴巴普惠体** 等国产免费商用字体

下载后把 `.ttf`/`.otf` 重命名为 `ui.ttf` 放进本目录即可。

> 提示：完整 CJK 字体可能有几 MB ~ 十几 MB。若在意体积，可用工具（如
> `fonttools pyftsubset`）裁剪出只含常用汉字 + 拉丁的子集后再放入。
